#Crumble Cafe

Сайт кофейни.

## Что тут сделано
* **Главная страница** - там написано «Добро пожаловать в Crumble Cafe!» и описание «Лучшая выпечка в городе, приготовленная с любовью.»
* **Кнопки сверху** - «Главная», «Меню», «Контакты». Нажимаются и переключают на выбранную вкладку.
* **Дизайн** - всё бежево-коричневое, потому что это кофейня.
* **Функционал** - прописанный в стиле плавный переход между вкладками, эффект hover на кнопках

Для запуска проекта на локальном компьютере выполните следующие шаги:

1. Установите все необходимые зависимости и пакеты:
   ```bash
   npm install
   ```

2. Запустите проект в режиме разработки:
   ```bash
   npm start
   ```

После этого приложение автоматически откроется в вашем браузере по адресу `http://localhost:3000` (или другом свободном порту).
